## 偏差原因分析（均为已知精度限制，非 bug）

### 1. 海南岛 / 舟山群岛不在多边形内（影响 4 例）
- `CHINA_COASTLINE` 注释明确"不含海南/台湾等岛屿"。
- 威马逊 2014、韦帕 2019：首次登陆海南文昌，app 漏检海南，报广东/雷州二次登陆。
- 灿鸿 2015：登陆舟山群岛（lng≈122.1），多边形大陆边界在 lng<122，未检出。
- 梅花 2022、烟花 2021：首次登陆舟山，app 报上海二次登陆。
- **属审计计划 C 节"已知精度限制"第 2 条**（简化多边形），不修复。

### 2. 采样跳跃 jumpKm（影响 5 例）
- NMC 路径点 3-6h 采样，登陆点 = 首个陆上采样点 `b`，真实穿越点在 `a→b` 之间。
- 森拉克 2002（jump=159km）、圆规 2004（jump=192km）、苏拉 2023 等：首个陆上点偏离真实登陆点 150-200km。
- **属审计计划 C 节"已知精度限制"第 1 条**，不修复（不插值）。

### 3. 邻国登陆后进入中国（影响 1 例）
- 布拉万 2012：实际登陆朝鲜半岛西海岸，路径点 `a(44.6,127.2)→b(46.3,129.4)` 跨 255km，app 把进入黑龙江的首个点当"首次登陆"。
- **属审计计划 C 节"已知精度限制"第 1、4 条**，不修复。

## 结论

1. **多边形修正成功**：渤海假陆地、西部中越边境、雷州半岛三处 bug 已修复，4 处副本（`index.html` / `build-typhoon-index.js` / `audit-landfall.js` / `rebuild-landfujian.js`）同步。
2. **样本核对通过**：21/30 一致，7/30 偏差均可由已知精度限制解释，2/30 漏检中天秤为正确排除、灿鸿为舟山群岛限制。
3. **无新 bug 引入**：`landFujian` 计数稳定 161（修正区均不影响福建），`fujianMismatch` 为 0。
4. **巴威基准保持**：仍为"浙江温州 07-12 01:00"，与用户确认一致。
